## hledger not found

This `hledger` codeblock requires [hledger](https://hledger.org/) — `hledger` must be on your `$PATH`.

### Install

**Debian / Ubuntu**
```bash
sudo apt install hledger
```

**Arch**
```bash
sudo pacman -S hledger
```

**macOS**
```bash
brew install hledger
```

**Any platform (latest)**
```bash
curl -sO https://raw.githubusercontent.com/simonmichael/hledger/master/hledger-install.sh
bash hledger-install.sh
```

After installing, verify with `hledger version` then reload this page.
