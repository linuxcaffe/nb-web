## Taskwarrior not found

This `tw` codeblock requires [Taskwarrior](https://taskwarrior.org/) — `task` must be on your `$PATH`.

### Install

**Debian / Ubuntu**
```bash
sudo apt install taskwarrior
```

**Fedora**
```bash
sudo dnf install task
```

**Arch**
```bash
sudo pacman -S task
```

**macOS**
```bash
brew install task
```

Once installed, initialise with `task version` then reload this page.
