# Welcome to nb-web

Your notes are plain Markdown files in `~/.nb/`: one folder per notebook, each its own git
repository, so every change is kept. This is **home**, your first notebook.

## Set up

Click a box to create it; the ones that need a name ask for it first. Clicking **Notebooks**
creates all three.

```add
org welcome
```

## Getting around

- **Add**, at the top, makes a new note in the notebook you're looking at; **List** shows its
  notes.
- The selector under the logo (it says **home** now) switches notebooks.
- Every note is a file you can also open in any editor, or with `nb` in a terminal: nb-web runs
  on top of it.

This note is yours: edit it, or delete it once you're settled.
