Appearance

Stored in browser localStorage. Only the content area switches; nav and menus stay dark.

Show folders above notes in the list. Default: on.

Amber progress strip shown above the preview while inline includes are fetching. Auto shows it only when 5+ includes are pending. Always shows it for any render. Never disables it.

Codeblocks

Launch URLs enable the ⎋ button on each block type. Leave blank to hide the button.

Clicking "hledger" in any block launches this command. Unchecked: starts as web service, opens in new browser tab (add --serve to suppress auto-browser). Checked: runs in the nb-web terminal panel (for TUI apps like hledger ui).

Clicking "task" in any tw block launches this command. Unchecked: opens in new browser tab. Checked: runs in the nb-web terminal panel (e.g. tasksh).
